# Universal working agreements

- Explain clearly and prefer small, understandable changes.
- Read the project's instructions and existing patterns before editing.
- Keep changes focused on the requested task.
- Verify changed behavior with appropriate project checks.
- Protect credentials and existing user changes.
- Never edit environment-variable files without the user's authorization.
- Ask before destructive Git operations or amending commits.
- Check Git status before committing; keep commits atomic and meaningful.
